## Benchmark Plan — 2026-10-01

### Selected Experiments (rank by expected ROI)

The following experiments target the specific architectural advantages of the DGX Spark cluster (NVIDIA GB10 Grace Blackwell Unified Memory) and the latest engine optimizations (HiSparse, Rust-native processing, NVFP4 MoE).

#### [1]. HiSparse Admission Logic vs. Standard PagedAttention — [vLLM]
**Hypothesis**: The new `HiSparse` admission logic in vLLM v0.30.0+ will significantly reduce TTFT variance and improve sustained throughput under high concurrency (bursty traffic) compared to standard PagedAttention, by offloading KV-cache management overhead to the unified host memory and preventing GPU livelocks.
**Setup**:
  - Model: **Llama-3-70B** (Fits comfortably in 128GB/GB10 with BF16; leaves room for KV cache overhead).
  - Framework version: `vllm==0.30.0` (with `--enable-hisparse` flag enabled).
  - Node config: **Single-node** (`spark-01`) to isolate memory management overhead from network latency.
  - Parallelism: TP=1 (Tensor Parallelism not needed for 70B on GB10 single chip, but we test memory bandwidth limits).
**Benchmark script** (runnable bash, use venv at ~/inference-bench-env or docker):
```bash

# Prerequisites: conda env 'vllm-bench' with vllm 0.30.0 installed
# Model download: huggingface-cli download meta-llama/Llama-3-70B-Instruct

cd ~/projects/vllm
python -m vllm.entrypoints.api_server \
  --model meta-llama/Llama-3-70B-Instruct \
  --tensor-parallel-size 1 \
