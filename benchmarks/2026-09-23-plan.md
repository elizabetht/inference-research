#### [1]. **DeepSeek-V4.1-Flash with MXFP8 KV Storage (vLLM v0.30.0)** — vLLM
**Hypothesis**: Leveraging MXFP8 KV storage and FlashMLA V4.1 on Blackwell will yield ~2.3x throughput improvement over vLLM main (pre-v0.30.0), with 40% lower memory footprint, due to reduced KV cache size and fully GPU-optimized memory access via async Engram prefetch and DP sharding.

- Model: `DeepSeek-V4.1-Flash-8B` (fits in 128GB unified memory; MoE-like structure but 8B active params)
- Framework version: `vllm==0.30.0` (from `main` branch, `commit: a9f1b3e` — confirmed support for SM100, MXFP8, FlashMLA V4.1)
